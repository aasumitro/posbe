## Features

### Shifts
- make admin be able to open and close shift before taking any orders
- when shift doesn't active prevent users (waiters, cashiers, and others) to place an order
- for open shift they should select the specified shift to open and put the current money in the box
- for close they also have to put the last money on the box

### Seating
- in here they can set the table status (via http call api)
- also can listen/subscribe to table status (over SSE or WS)
